# Ввод механизма файлового обмена

Получатели: все Сущности, перечисленные в `ENTITY-MAP.md`.

В `wellbeing-hq` введён рабочий механизм публикации, адресной передачи, receipt и распределённого реестра.

Обязательные locator'ы:

- `FILE-EXCHANGE-PROTOCOL.md`
- `registry/README.md`

Требуемое действие для каждой Сущности:

1. При следующем значимом файловом результате использовать собственный `outbox/` этого репозитория.
2. При передаче другой Сущности создать адресный dispatch и запись в собственном `registry/by-sender/<entity>.jsonl`.
3. Не использовать ОПЕРАТОРА как ручной транспорт файлов, если публикация и dispatch доступны инструментально.
4. Receipt отделять от содержательного acceptance.

Этот dispatch не требует ответного документа только ради подтверждения ознакомления. Применение механизма проверяется на первом реальном обмене.
