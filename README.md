# ШТАБ БЛАГОПОЛУЧИЯ

Операционный репозиторий проекта: постоянные адреса Сущностей, рабочие входы/выходы, handoff и receipts.

Правило: значимый артефакт не должен зависеть от памяти ОПЕРАТОРА, локальной папки смартфона или догадки адресата.

Структура каждой Сущности:
- `inbox/` — входящие материалы;
- `outbox/` — готовые рабочие результаты;
- `current/` — проверяемые указатели на текущее рабочее состояние;
- `handoff/` — адресные передачи;
- `receipts/` — подтверждения доставки/получения.

`routes/` хранит общий dispatch/receipt слой. `registry/` — реестр адресов и назначений.

Этот репозиторий не заменяет active Project Sources, recovery-репозиторий или wellbeing-experience.
