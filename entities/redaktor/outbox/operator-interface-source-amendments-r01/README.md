# Пакет поправок: человекочитаемый результат и decision packet ОПЕРАТОРУ r0.1

Назначение: устранить выявленный операционный дефект, при котором Сущность возвращает технический terminal result без понятного следующего шага, а КООРДИНАТОР при approval-gate отправляет ОПЕРАТОРА собирать уже существующие основания по другим Entity-чатам.

В GitHub-пакете фиксируется точная минимальная дельта к трём действующим источникам:
1. project core — общая норма human-facing результата и явного следующего шага ОПЕРАТОРА;
2. task-conveyor canon — обязательный decision packet на Operator gate и запрет гонять ОПЕРАТОРА за уже доступным evidence;
3. entity roles — короткое закрепление обязанностей ОПЕРАТОРА/KOO.

Полные candidate-копии этих трёх источников подготовлены RED как рабочие файлы для проверки, но каноническое source publication/activation принадлежит KAN/KOO по действующей процедуре.

Не изменяются:
- file-work canon: уже требует «не перекладывать на ОПЕРАТОРА догадки» и давать короткую конкретную инструкцию;
- source-loading policy: порядок загрузки источников не меняется;
- recovery canon: сохранение/восстановление состояния не затрагивается.

Статус: содержание поправок прямо разрешено ОПЕРАТОРОМ в текущем RED-чате; canonical source materialization + activation/readback ещё должны быть выполнены ответственным нормативным контуром.
