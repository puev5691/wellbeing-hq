# КООРДИНАТОР → ШТАБИСТ: аудит незакрытых маршрутов HQ

## Задача

Проверить `puev5691/wellbeing-hq` и выявить фактически незакрытые адресные обмены между Сущностями.

Нужен не общий отчёт о «состоянии проекта», а узкая проверка маршрутизации:

1. найти dispatch/inbox locators без receipt;
2. найти receipt без отдельного acceptance/rejection там, где содержательное решение требовалось;
3. найти результаты в outbox адресата, которые не были возвращены в inbox отправителя;
4. найти очевидно завершённые обмены, которые продолжают выглядеть активными из-за незакрытой служебной фиксации;
5. отдельно отметить случаи, где выполнение зависит от ручного «пинка» ОПЕРАТОРА.

## Результат

Один standalone Markdown-файл с таблицей/перечнем только подтверждённых случаев: artifact/route, sender, recipient, текущее доказанное состояние, чего именно не хватает для закрытия, locator на доказательство.

Не исправлять маршруты самостоятельно, если исправление требует содержательного решения другого владельца. Технические очевидные служебные хвосты можно указать как `mechanically_closable`.
