# Задание АРХИВАРИУСУ: собрать проверяемый source-pack для публичного выступления

## Назначение
ОПЕРАТОР готовит через примерно 10 часов публичный монолог о смысле использования технологий проекта «Благополучие» в формировании кооперации социальных групп и индивидуумов. Материалы разбросаны, часть имеет разный статус. Нужен компактный проверяемый пакет источников, чтобы РЕДАКТОР и КООРДИНАТОР не сочиняли красивую чепуху из воздуха.

## Задача
По доступным подтверждённым материалам проекта собрать минимальный source-pack для выступления. Не весь архив.

Выделить:
- действующие Project Sources, определяющие смысл/роль проекта и Сущностей;
- подтверждённые материалы о COOP/кооперации;
- подтверждённые материалы о WBN/WBNP и механизмах вознаграждения/обмена, если они доступны;
- уже существующий каркас/наброски выступления, если доступны;
- три намеченных исследования и их фактический статус/locator, если они подтверждаются;
- материалы, которые нельзя использовать как факт из-за candidate/draft/устаревшего/неясного статуса.

Для каждого элемента: locator, immutable identity если доступна, статус, 1–3 предложения о том, что именно из него можно использовать в выступлении.

## Результат
Один файл `ARH__speech-source-pack__KOO.md` в `entities/arhivarius/outbox/`, затем адресный возврат в `entities/koordinator/inbox/`.

В начале: «10 главных опор для выступления». В конце: «Что нельзя утверждать со сцены по имеющимся источникам».

## Приоритет
Срочный. Результат нужен в пределах текущего 10-часового окна подготовки выступления.
