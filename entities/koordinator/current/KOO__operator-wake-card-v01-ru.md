# КООРДИНАТОР — операторская карточка пробуждений v0.1

Статус: `АКТУАЛЬНАЯ_ОПЕРАТОРСКАЯ_КАРТОЧКА`

Назначение: ОПЕРАТОР не читает inbox Сущности, не пересказывает задачу и не пишет длинный промпт. КООРДИНАТОР заранее материализует exact task в GitHub. ОПЕРАТОР только открывает нужный чат и вставляет короткий адресный wake-промпт ниже.

Главное правило:

> один чат → один короткий промпт → дальше Сущность сама делает Resume-First, fresh preflight, читает свой exact inbox и возвращает результат через Exchange Gate.

Если Сущность просит ОПЕРАТОРА повторить содержание уже адресованного файла, сначала она должна самостоятельно прочитать свой inbox. Ручной пересказ ОПЕРАТОРОМ не является штатной частью процесса.

## Нормативная граница интерфейса ОПЕРАТОРА

ОПЕРАТОР не обязан:
- открывать файлы очереди перед каждым wake;
- сверять commit/blob вручную;
- читать старый чат Сущности;
- пересказывать Сущности её задачу;
- перечислять все запреты и зависимости;
- определять, какой inbox item актуален.

Это обязанности KOO + Resume-First самой Сущности.

ОПЕРАТОР требуется только там, где действительно нужен human gate: ручной wake до появления exact-chat resume, секрет/credential input, отдельное high-impact решение, интерактивный sudo или иной неделегируемый шаг.
