## 1. Telegram Phase 1B

ОПЕРАТОР разрешил использовать любой допустимый технический способ, который позволит настроить и в дальнейшем применять требуемые инструменты.

ОПЕРАТОР готов участвовать в реализации в тех объёмах, где нужен человеческий ввод, подтверждение, действие в панели провайдера, выдача/установка доступа или иное действие, которое невозможно безопасно выполнить автоматически.

Это решение снимает прежний blocker `WAITING_OPERATOR_AUTHORIZED_EXECUTION_DECISION`.

Разрешённый следующий профильный владелец: SIS / СИСАДМИН.

SIS вправе подобрать и реализовать работоспособный privilege/tooling path, включая оператор-assisted действия, если они нужны.

Границы, которые этим решением НЕ снимаются автоматически:
- не публиковать пароли, приватные ключи, токены и иные секреты в GitHub;
- не считать production/live Telegram send разрешённым только из факта настройки privilege path;
- перед значимым runtime mutation выполнить fresh host preflight и проверить фактический scope;
- если выбранный путь затрагивает сторонний billing, необратимое действие или существующий production contour, отдельно обозначить это ОПЕРАТОРУ до исполнения.

## 2. Первый внешний многомодельный маршрут

ОПЕРАТОР выбрал Anthropic как первый практический внешний provider route.

Причина приоритета: личный интерес ОПЕРАТОРА, подогреваемый публичной информацией. Это не техническое утверждение о превосходстве Anthropic над Google.

Google остаётся допустимым резервным/сравнительным маршрутом.

Текущий разрешённый класс первого внешнего пилота:
`D0_SYNTHETIC`.

Разрешено:
- готовить прямую интеграцию с Anthropic Claude API;
- готовить credential-free adapter/code/config;
- исследовать цены, rate limits, доступные модели, контекст, tool use и другие технические возможности;
- после появления учётных данных выполнить отдельный bounded D0 pilot в пределах явно зафиксированного бюджета/модели.

Не считается автоматически разрешённым:
- передача private/project-sensitive данных;
- D2+;
- production routing;
- публикация API key;
- произвольный fallback на другие providers;
- неограниченный расход средств.

## 3. Текущий человеческий запрос

ОПЕРАТОРА интересуют:
- цена доступа;
- способы доступа;
- технические возможности Anthropic/Claude;
- практический первый путь подключения к проекту.
