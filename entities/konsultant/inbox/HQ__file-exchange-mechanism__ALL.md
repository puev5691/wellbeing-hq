# Новый механизм файлового обмена

Для этой Сущности введён рабочий файловый маршрут через `puev5691/wellbeing-hq`.

Прочитать и применять:
- `FILE-EXCHANGE-PROTOCOL.md`
- `registry/README.md`
- `routes/dispatch/HQ__file-exchange-mechanism__ALL.md`

На первом следующем значимом обмене проверить полный цикл: свой `outbox/` → адресный `dispatch` → запись в своём sender-журнале → receipt адресата.

ОПЕРАТОР не должен вручную переносить файл между Сущностями, если Сущность может выполнить публикацию и dispatch сама.
