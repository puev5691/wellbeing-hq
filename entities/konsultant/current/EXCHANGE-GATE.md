# Exchange Gate — current

Для межсущностного обмена действует обязательный operational gate из `EXCHANGE-GATE.md` и `FILE-EXCHANGE-PROTOCOL.md`, основанный на действующем утверждённом файловом каноне.

Передача не считается завершённой по факту создания файла или публикации. Если доступный инструмент позволяет Сущности самой опубликовать и адресно доставить артефакт, передача через ОПЕРАТОРА запрещена как рабочий shortcut.

Перед заявлением `delivered/received/complete` проверить полный маршрут и `EXCHANGE_GATE=PASS` для gate-v1 dispatch. Receipt не означает acceptance.

Если gate выполнить невозможно из-за отсутствия полномочий/инструмента, фиксируется конкретный blocker и только тогда запрашивается минимальное ручное действие ОПЕРАТОРА.
