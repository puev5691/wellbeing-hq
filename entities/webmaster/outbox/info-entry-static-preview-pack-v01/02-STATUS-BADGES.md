# Status Badge Vocabulary

Primary: `PUBLIC-READY / SYNTHETIC`, `CANDIDATE / NOT CURRENT`, `BLOCKED / NOT PUBLIC`, `SUPERSEDED`, `SECRET-LIKE / BLOCKED`, `WITHDRAWN`.

Dimension badges preserve independent states:

- semantic: CURRENT / CANDIDATE / SUPERSEDED / WITHDRAWN / UNKNOWN;
- editorial: UNASSESSED / DRAFT / REVIEWED / READY / BLOCKED / SUPERSEDED / WITHDRAWN;
- public/legal: ALLOWED / ALLOWED WITH CONDITIONS / BLOCKED / UNKNOWN;
- security: PUBLIC SAFE / SIS REVIEW REQUIRED / BLOCKED SECRET / UNKNOWN / N/A;
- representation: PREVIEW READY / PREVIEW BUILT / REPRESENTATION READY / BLOCKED / SUPERSEDED / WITHDRAWN;
- release: AUTHORIZED / UNASSESSED / BLOCKED / WITHDRAWN.

Primary precedence: secret/security block → legal/editorial/profile block → withdrawn → superseded → candidate → public-ready synthetic.

A positive badge never hides a stronger block.
