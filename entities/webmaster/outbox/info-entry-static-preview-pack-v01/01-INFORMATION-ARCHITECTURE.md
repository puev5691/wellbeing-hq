# Static Preview Information Architecture

Always show: **NON-PRODUCTION STATIC PREVIEW — STATUS IS NOT AUTHORITY**.

## Buckets

1. **Current / Public-ready** — only fully eligible objects. Fixture: POSITIVE.
2. **Research / Candidate** — visible review area, permanently non-current. Fixture: CANDIDATE.
3. **Historical / Superseded** — old versions with successor/stale warning. Fixture: SUPERSEDED.
4. **Withdrawn** — preserved withdrawal record, never current. Fixture: WITHDRAWN.
5. **Blocked / Quarantine** — internal test-only placeholder, absent from public nav. Fixtures: BLOCKED, SECRET-LIKE.
6. **Operational evidence** — excluded by default; only explicit public-safe projections later.
7. **External references** — external/attributed, never project authorship by implication.

## Page order

banner → title → primary badge → dimension badges → safe body/placeholder → provenance → parent/derivative → supersede/withdrawal → test-only readback assertions.

## Invariants

Candidate never appears Current. Blocked never appears public nav. Superseded never replaces successor. Withdrawn never appears current. Missing applicable gate fails closed.
