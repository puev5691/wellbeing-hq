## Предлагаемая добавка к роли WEB

В пределах утверждённого веб- и медийного контура WEB может исследовать, проектировать и применять AI-assisted workflows для разработки, документации, web-quality, публикационных производных материалов, поиска и contributor experience.

## Разрешаемый класс действий после отдельного утверждения

WEB может:

- использовать GitHub Copilot и эквивалентные инструменты для bounded research/code tasks;
- запрашивать AI code review;
- готовить repository instructions для web-контуров;
- проектировать WEB-specific Agent Skills;
- применять AI для анализа результатов Lighthouse/link/accessibility/SEO инструментов;
- применять AI для подготовки candidate metadata, summaries, teasers, translations и alt-text;
- сравнивать результаты нескольких моделей;
- проектировать provider-neutral adapters для web/media use cases.

## Не передаётся AI

Ни Copilot, ни внешний AI не получает автоматически право:

- утверждать канон;
- принимать результат от имени профильной Сущности;
- делать auto-merge значимых изменений;
- менять production;
- публиковать репутационно/юридически значимый материал без approval;
- определять юридическую или финансовую политику;
- считать собственный вывод доказательством факта;
- получать секреты или полный проектный архив без необходимости.

## Граница WEB / KOD / KOO

WEB владеет AI-assisted web/media workflow.

KOD требуется для общепроектного AI broker, MCP/A2A services, backend и общей библиотеки agent tooling.

KOO утверждает межсущностную модель прав, автоматизацию действий и использование AI как общепроектного контура.

## Особая рекомендация

Исследовать Agent Skills и AGENTS.md как возможный формат передачи проверенного опыта новым Сущностям и внешним coding agents.

Это candidate-гипотеза и не заменяет действующий recovery/инициационный канон.
