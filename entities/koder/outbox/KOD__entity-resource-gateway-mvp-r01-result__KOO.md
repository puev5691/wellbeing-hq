## Границы, которые не расширялись

Первая версия принимает только общий проверочный payload `Synthetic bounded request.`: это ограничение неизменённого Anthropic-адаптера. Другой текст отклоняется, а не заменяется молча. Модель Anthropic остаётся тестовой; права аккаунта и доступность реальных моделей не подтверждаются. Следовательно, это библиотечный синтетический прототип, не живой шлюз произвольных подзадач.

Внешний доверенный verifier должен подтвердить вызывающую Сущность, точную задачу и текущие полномочия. По умолчанию допуск закрыт; тестовая функция равенства не является проверкой реального человека или writer. Внутренний исторический контекст Anthropic-адаптера записан отдельно и не подменяет requester/task общего результата.

Результат модели остаётся данными: `project_acceptance=NOT_GRANTED`, `caller_writer_changed=false`, полномочия gateway/provider отсутствуют, автоматическое применение к проектному состоянию и внешняя отправка выключены. Контрольная сумма доказывает совпадение, не истинность ответа. Точка интеграции: проверенный requester → запрос → закрытая политика → существующий оркестратор/адаптер → ресурс → отдельная приёмка вызывающей Сущностью.

По сравнениям GitHub начальная граница → prewrite и prewrite → полный пакет не менялись writer-маркеры, исходные адаптеры, Telegram Phase 1B и facilitator core. Наблюдались только новые файлы этой задачи, другой отчёт и отдельные записи SIS. Это сравнение репозиторных изменений, не проверка работающего Telegram. Production, billing/account, automation, recovery и TERA2/WBN не затрагивались.
