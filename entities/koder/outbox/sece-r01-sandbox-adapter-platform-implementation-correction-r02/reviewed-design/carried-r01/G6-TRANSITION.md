# G6 Transition Boundary
status: DESIGN_ONLY

A valid G4+G5 sandbox PASS may establish only:
- exact adapter/effect class worked for exact candidate/version and exact sandbox target class under exact authority/evidence conditions;
- pre-effect admission/invocation drift checks operated as evidenced;
- outcome and cleanup evidence chain was sufficient for that attempt;
- no production spillover was observed within declared review scope.

It may NOT establish:
live/production authority; deployment; reusable authority; provider/service safety beyond tested class; source/canon effectivity; universal reliability; exactly-once semantics; automatic activation; production target suitability.

Any G6 decision is separate, OPERATOR-controlled, exact-scope/version/effect-class bound.
