# Presentation specification r0.2

> **NON-PRODUCTION PREVIEW — НЕ ПУБЛИЧНЫЙ РЕЛИЗ**

## Основное правило

Внешний слой сначала объясняет человеческим русским языком: что это, что подтверждено и что ещё не подтверждено. Machine status/verdict, commit, blob и path остаются вторичной provenance-информацией и могут раскрываться отдельно.

## Ярлыки состояния

- `draft` → **Черновик**;
- `working` → **Рабочий материал**;
- `working skeleton` / `skeleton` → **Рабочий каркас / Каркас**;
- `candidate` → **Кандидат**;
- `STALE_RISK` → **Актуальность не подтверждена**.

Исходный literal status сохраняется в технических метаданных.

## Текущие разработки

Public information portal: **разрабатываемый информационный портал; сейчас доступен только непроизводственный слой представления для проверки**.

Entity AI resource boosters: **направление разработки, проходящее отдельные технические проверки перед ограниченным live-исполнением**.

Telegram facilitator: **направление разработки; запуск ожидает отдельной технической подготовки с необходимыми полномочиями**.

Нельзя отображать эти направления как «доступно», «запущено» или «работает» без отдельного release/deployment evidence.

## Завершённые проверенные рубежи

Сначала показывается смысл:
- **Сформирована ограниченная непроизводственная базовая модель информационного входа.**
- **Принят контракт представления статического preview.**
- **Закрыта узкая повторная проверка Static Preview v0.3 E1.**
- **Пройдена межслойная повторная проверка информационного входа r2.**

Exact verdict каждого рубежа остаётся во вторичной технической карточке. Эти рубежи не означают публичный запуск портала.

## Ожидающие проверки и ограничения

Публичный заголовок вместо «Активные блокеры и gates»: **Ожидающие проверки и ограничения**.

AI boosters: **до ограниченного live-вызова остаются проверки доступа к провайдеру и учётной записи, разрешённой модели, защищённого доступа и отдельного разрешения на вызов**.

Telegram Phase 1B: **запуск ожидает отдельной технической подготовки с необходимыми полномочиями**.

Portal release: **публичный выпуск не разрешён; часть материалов остаётся черновой или кандидатной, отдельного разрешения на выпуск нет**.

Приватные runtime paths, конфигурация и provisioning details в публичный слой не выводятся.

## Пустые состояния

Кооперация: **Публичное представление кооперации ещё не прошло необходимую проверку. Это не означает отсутствие самой работы по кооперации.**

Публикации: **Для этой версии ещё не выбран утверждённый публичный индекс публикаций.**

Отозванные материалы: **В эту версию не включены проверенные публично допустимые объекты данной категории. Это не является утверждением, что отозванных материалов вообще нет.**

## История

Публичное название: **История и заменённые версии**.

Технический bucket `superseded` и соответствующие metadata сохраняются без изменения.

## Provenance

Commit/blob/path/verdict не являются основным чтением. UI должен показывать их во вторичном или раскрываемом блоке «Технические сведения и происхождение».

На каждой candidate/draft странице и в верхней части preview должна оставаться заметная маркировка непроизводственного состояния.
