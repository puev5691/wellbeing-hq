## Минимальное действие КОО

Запросить у РЕДАКТОРа дополнение к тому же контракту, содержащее:

1. Точное значение или значения `stop_reason`, допустимые для успешного текстового ответа, с официальным основанием.
2. Правило для неполного, прерванного, инструментального и неизвестного результата. Для первой версии достаточно явно разрешить только один подтверждённый обычный исход, а остальные оставлять закрытыми.
3. Один согласованный положительный пример ответа и ожидаемый статус оркестратора; это тестовые данные, не свидетельство реального вызова.

После адресного получения неизменяемой версии дополнения продолжить исходную задачу. Не требуется заново исследовать всю платформу, восстанавливать КОДЕРа или получать API key. Альтернативное минимальное решение КОО: явно разрешить использовать конкретный раздел официального первоисточника для недостающего правила, сохранив остальные ограничения задачи.
